# JPMorgan Chase – Midas Core Simulation (Forage)

Backend financial transaction processing system built using Java and Spring Boot.

## What this project demonstrates

• Kafka-based event-driven transaction processing  
• REST API development using Spring Boot  
• External incentive service integration via REST calls  
• Database persistence using JPA + Hibernate + H2  
• Balance lookup endpoint implementation  
• Debugging multi-service backend workflow  

## Tech Stack

Java  
Spring Boot  
Apache Kafka  
REST APIs  
JPA  
H2 Database  
Maven  

## Key Features Implemented

Transaction Kafka Listener  
Transaction persistence layer  
Incentive API integration  
Balance REST endpoint (`/balance?userId=`)  
Automated test execution with TaskFiveTests  

## How to Run

1. Start the Incentive API service
2. Run the Spring Boot application
3. Execute TaskFiveTests
